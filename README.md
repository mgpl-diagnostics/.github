# mgpl-diagnostics/.github

Organisation-wide files for [github.com/mgpl-diagnostics](https://github.com/mgpl-diagnostics).

- `profile/README.md` is the organisation's profile page.
- `profile/banner.svg` is generated by `scripts/make-banner.mjs`. Text is converted to vector paths from the
  Manrope font, and the logo comes from report-kit. Run the script inside the local MGPL workspace.
- `scripts/protect-repos.mjs` applies the repository rules to every repo (PR-only `main`, required CI and
  code-owner review, maintainer-only release tags, private vulnerability reporting). Re-run it after creating
  or publishing a repo: `node scripts/protect-repos.mjs` (add `--dry-run` to preview).
- `.github/` holds the default community files every repo inherits: issue forms, PR template, CONTRIBUTING,
  SECURITY, CODE_OF_CONDUCT and SUPPORT.
